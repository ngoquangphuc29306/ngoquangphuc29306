Featured Project
SafeNest-AI — AI-Assisted Student Housing
An in-development project exploring how AI can help students make more informed decisions when looking for rental housing.

Areas of work and exploration:
- Document understanding: OCR-based extraction of information from rental-related documents
- Retrieval-augmented generation: Legal-document parsing, structure-aware chunking, and retrieval workflows
- Backend integration: Connecting AI capabilities with application services
- Reliability: Preserving source context and improving the traceability of generated answers
Technologies involved: Python · FastAPI · RAG · Supabase / PostgreSQL
